单页应用，由 index.html 作为入口，app.js 承担全部业务逻辑（数据加载、过滤/排序、虚拟滚动、书签、对比、分享、键盘导航、i18n），styles.css 提供主题与布局，sw.js 通过 Cache API 实现离线缓存，manifest.json 注册为 PWA（standalone display）。运行时依赖 ../data/repos.json 提供的 JSON 数据，无后端；通过 try-catch 回退到 ./data/repos.json 与 data/repos.json 以兼容不同部署路径。模块内部按职责划分：I18N/LANG_ICONS/TAG_KEYWORDS 等常量表 → 状态管理（allRepos/bookmarkedRepos/currentLang 等全局变量）→ 数据层（loadRepos/filterAndSort/renderVirtualRepos）→ UI 渲染（createCard/openModal/showToast）→ 事件绑定（DOMContentLoaded 监听器在文件末尾集中注册）。
