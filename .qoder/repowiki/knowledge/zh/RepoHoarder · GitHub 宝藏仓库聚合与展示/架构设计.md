仓库按职责拆分为三个子模块：data_pipeline 负责通过 Awesome Lists、GitHub API、Hacker News 与 DEV.to 抓取并生成 data/repos.json；web_app 作为纯前端静态站点消费该 JSON 文件渲染卡片网格、筛选排序与收藏；mind_coach_research 独立沉淀心力教练项目的研究档案，不依赖前两者。三者通过 data/repos.json 这一共享文件边界解耦——pipeline 产出、web_app 消费，彼此无运行时耦合；requirements.txt 集中声明 pipeline 所需的 requests 与 beautifulsoup4 依赖。
