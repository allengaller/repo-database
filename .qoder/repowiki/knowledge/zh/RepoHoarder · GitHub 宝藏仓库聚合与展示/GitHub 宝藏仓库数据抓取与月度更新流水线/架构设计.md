本模块由两个独立可执行的 Python 脚本组成，共享同一份 JSON 数据契约（data/repos.json），无内部包划分。
- scripts/scrape.py：一次性全量抓取入口。按 [1/6]..[6/6] 阶段顺序调用 fetch_awesome_lists → fetch_from_api → fetch_trending_repos → fetch_hackernews → fetch_devto_articles，统一经 merge_and_sort 去重（同名仓库取 stars/forks/today_stars/commit_activity 字段最大值、合并 source 标签）后计算 score = stars + forks + (forks/stars)*1000 + today_stars*10 + commits_4w*2，最终写入 data/repos.json。
- scripts/update_monthly.py：按月增量补采入口，基于 argparse 接受 --year/--month/--report；通过 created:YYYY-MM-DD..YYYY-MM-DD 时间窗 + language/topic/rising-stars 四类查询拉取当月新仓库，merge_with_existing 覆盖同名条目并按 score 重新排序，同时可选生成 data/monthly_report_{year}_{month}.md。
- 外部依赖方向单向：两个脚本仅读/写 data/ 目录，通过 requests 访问 GitHub Search API、stats/commit_activity、Hacker News Firebase、DEV.to API 以及 awesome-* 列表的 raw README；GITHUB_TOKEN 通过环境变量注入，未设置时走 60 req/h 匿名配额。
- 数据模型：每个 repo 对象包含 name/url/description/stars/forks/language/today_stars/score/fetched_at/source 等字段，monthly_new 来源额外带 created_at 与 month_tag，供前端 “Surge Index” 与月度报表消费。
