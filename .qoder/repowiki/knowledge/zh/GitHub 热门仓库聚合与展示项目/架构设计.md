根目录作为编排层，按职责拆分为三个子模块并通过文件边界解耦：
- data_pipeline 产出 data/repos.json（Awesome Lists/GitHub API/Hacker News/DEV.to 多源抓取 + 去重评分）；
- web_app 作为纯前端静态站点消费该 JSON 渲染卡片网格、筛选排序与收藏；
- mind_coach_research 独立沉淀心力教练项目的三轮研究档案，不依赖前两者。
三者无运行时耦合，仅通过 data/repos.json 共享数据契约；requirements.txt 集中声明 pipeline 所需的 requests 与 beautifulsoup4 依赖。
