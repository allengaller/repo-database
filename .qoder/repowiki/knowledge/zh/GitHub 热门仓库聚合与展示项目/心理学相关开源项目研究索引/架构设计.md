本模块为纯文档型研究目录，无代码实现，采用「总览索引 + 单项目专题报告」的扁平结构：
- `INDEX.md` 作为根入口，按三大类（AI+心理咨询/治疗、AI Agent+心理健康、冥想/正念应用）组织全部 11 个项目，并提供技术维度对比矩阵与「心力教练相关性评估」表格。
- 每个项目对应一个独立 Markdown 文件，命名遵循 `{项目名称}_{仓库名}.md` 规范，内容统一包含项目基本信息、技术栈分析、核心功能特性、应用场景说明、优缺点评价及相关论文/参考资料链接。
- 依赖方向单向：各专题报告被 INDEX.md 引用，模块之间不互相引用；与「心力教练研究」通过外部仓库 peace-lab-global/hush.ai 的 `knowledge/mind-coach/` 目录建立交叉阅读关联。
