- 所有对外 HTTP 请求统一通过 get_headers() 构造 User-Agent 与 Authorization 头，并在 403 时打印 rate limited 消息后 time.sleep(5) 退避重试。
- 第三方库（requests）采用 try/import + sys.exit(1) 的运行时自举模式，避免要求用户预先安装。
- 每个抓取函数返回以 full_name 为键的 dict，并通过统一的 format_api_repo / format_repo 将上游响应归一化为 {name,url,description,stars,forks,language,today_stars,score,fetched_at,source} 结构。
- 去重策略遵循同名仓库字段级取 max（stars/forks/today_stars/commit_activity）+ description 优先非空 + source 用 '+' 拼接集合的固定规则。
- score 计算公式在 scrape.py 与 update_monthly.py 中保持一致：stars + forks + (forks/stars)*1000，再叠加 today_stars*10 与 commit_activity*2 等活跃信号。
- 输出文件均使用 ensure_ascii=False + indent=2 的 json.dump 写入 UTF-8，并在写入前 os.makedirs('data', exist_ok=True) 确保目录存在。
