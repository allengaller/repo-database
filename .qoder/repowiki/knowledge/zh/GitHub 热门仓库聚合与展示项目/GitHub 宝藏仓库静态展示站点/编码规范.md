- 所有用户可见文案通过 I18N[currentLang][key] 字典 + t() 函数统一输出，避免硬编码字符串。
- SVG 图标以内联 SVG 字符串形式定义在 LANG_ICONS 常量中，按语言名索引复用。
- DOM 操作集中在 createCard / render* 函数中以模板字符串拼接，而非逐节点 appendChild。
- 持久化状态（theme、language、bookmarkedRepos）一律通过 localStorage.getItem/setItem 读写，并包裹 try/catch 防御损坏数据。
- 大型列表渲染采用固定 CARD_HEIGHT 的绝对定位虚拟滚动，visibleStart/visibleCount/BUFFER 控制可视窗口。
