零构建、零依赖的单文件 SPA：index.html 为入口并内联 <link rel="manifest"> 与 <script src="sw.js">；app.js 承担全部业务逻辑（数据加载、过滤/排序、虚拟滚动、书签、对比、分享、键盘导航、i18n），styles.css 通过 CSS Variables 提供 light/dark 双主题；sw.js 注册 Service Worker，对 shell 资源采用 stale-while-revalidate、对 /data/* 走 network-first + cache fallback，并在离线时回退到 offline.html；manifest.json 以 standalone display 注册 PWA。运行时依赖 ../data/repos.json，loadRepos 内部按 DATA_URL → ./data/repos.json → data/repos.json 顺序重试 fetch，兼容不同部署路径。模块内部按职责线性划分：常量表（LANG_ICONS/I18N/TAG_KEYWORDS/LICENSE_KEYWORDS）→ 全局状态（allRepos/bookmarkedRepos/currentLang 等）→ 数据层（loadRepos/filterAndSort/renderVirtualRepos）→ UI 渲染（createCard/openModal/showToast）→ DOMContentLoaded 末尾集中事件绑定。
