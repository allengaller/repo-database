本模块为纯文档型研究仓库，按“总索引 + 编号报告 + 开源项目子目录 + 发现脚本”四层组织：
- 顶层 `INDEX.md` / `00-EXECUTIVE-SUMMARY.md` 作为入口，串联 10 份编号 Markdown 报告（市场/竞品/认证/品牌/MVP/合规/理论/课程），每份报告独立成文件，形成线性递进的研究流水线。
- `repos/<repo>/REPORT.md` 对每个被深度分析的 GitHub 项目采用统一的 9 章模板（概览/基础信息/目录结构/核心分析/技术架构/教练启发/关键摘录/后续问题/相关资源），并通过 `discover-repos.py` + `discover-repos.sh` 以 JSONL 形式增量维护候选库，避免重复劳动。
- 可交付物单独存放于 `repos/Gemini-Abhidhamma-Alignment/PROMPT-ZH.md`（v5.3 中文版 System Prompt）与 `repos/vasana-poc/index.html`（熏习机制交互演示），与研究正文解耦，便于直接复用。
- 依赖方向单向：脚本 → discoveries.jsonl → 人工筛选 → REPORT.md → 综合报告；不存在代码级耦合，所有产出均为 Markdown/HTML/JSONL。
