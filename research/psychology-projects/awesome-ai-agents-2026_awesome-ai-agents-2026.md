
### 2. 心理健康方向的特色收录

#### Talkspace AI
- **架构**：Cloud + Multi-Agent
- **功能**：AI 辅助治疗匹配 + 人类治疗师备份
- **亮点**：将 AI 匹配与人类专业判断结合，实现"AI 初筛 + 人工确认"的安全模式

#### AI 心理健康伴侣
- **功能覆盖**：CBT + DBT（辩证行为疗法）+ 冥想
- **认证**：NHS（英国国家医疗服务体系）认证
- **隐私**：匿名使用，无需注册
- **亮点**：将多种循证治疗方法整合在一个 Agent 中

#### 21-day-self-interview
- **定位**：AI 存在主义心理顾问
- **功能**：每日 3 个问题引导自我反思和日志记录
- **标签**：agent, journaling, mental-health, mirror, psychology, self-improvement, self-reflection
- **亮点**：将存在主义哲学与 AI 结合，用于自我探索

### 3. 多维度分类

每个 Agent 按以下维度分类：
- **部署方式**：Cloud / Local / Hybrid
- **架构类型**：Single-Agent / Multi-Agent
- **交互方式**：Chat / Voice / API
- **认证状态**：是否通过医疗认证

## 五、优缺点评价

### 优势

1. **时效性强**：专注 2026 年最新 AI Agent，信息新鲜
2. **全领域覆盖**：不仅限于心理健康，便于跨领域发现灵感

4. **质量参差**：收录标准不明确，部分项目可能质量有限
