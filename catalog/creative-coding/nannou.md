## 二、技术栈分析

- 纯 Rust，基于 wgpu 的现代图形管线，窗口/绘图/音频/激光控制一体
- API 设计借鉴 Processing 的 setup/update/view 循环

## 三、核心功能特性

1. **类型安全的艺术**：编译器兜底让大型生成艺术项目可长期维护
2. **激光与硬件**：内置 LASER DAC 支持，可驱动实体激光装置
3. **wgpu 渲染**：跨平台现代 GPU 管线，性能与可移植性兼得

## 四、应用场景说明

- Rust 开发者进入生成艺术的首选框架
- 与本库 [alaya](../mind-philosophy/alaya.md)（Rust 记忆引擎）同语言生态，可组合做『心识可视化』实验

## 五、个人评价

### 优势

1. Rust 生态里最成熟的创意编程框架，MindBuffer 有真实装置作品验证

### 不足

1. 社区规模远小于 Processing 系，教程与案例偏少
2. 迭代速度受核心维护者带宽限制

### 评分理由

4 星：Rust × 生成艺术的代表框架，类型安全创作路线的标杆（⭐6.7k，截至 2026-07）。
