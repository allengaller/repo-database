## 二、技术栈分析

- 文档站基于 VuePress（仓库语言统计显示为 JavaScript），正文为 Markdown
- 内容按后端知识体系组织：Java 基础/集合/并发/JVM → 数据库（MySQL/Redis）→ 分布式与高并发 → 系统设计 → 求职攻略
- 近年持续扩充 AI 应用开发章节，跟上了大模型工程化的趋势
- 配套在线站点 javaguide.cn，支持全文搜索
- 社区 PR 驱动更新，作者负责审校口径，纠错响应快

## 三、核心功能特性

1. **持续活跃的中文指南**：最近提交 2026-08-24，同类停更项目中的异类
2. **深度超过八股**：多数条目带原理图解与源码级分析，不止于结论
3. **覆盖后端全链路**：从语言基础到分布式架构一篇不落
4. **求职软技能并入**：简历、面经、谈薪等章节一并收录
5. **许可友好**：Apache-2.0，做内部培训/语料二次加工无法律障碍

## 四、应用场景说明

- 国内 Java/后端岗位面试主复习材料：按目录系统性过一遍
- 非 Java 背景的工程师（如 Python/Go）：数据库、分布式、高并发章节是语言无关的通用知识
- 与 [cs-notes.md](cs-notes.md) 取舍：本项目更新更勤、深度更深；CS-Notes 更适合快速扫盲
- 与 [advanced-java.md](advanced-java.md) 配合：本项目打基础，后者攻进阶难题

## 五、个人评价

### 优势

1. 中文后端面试资源里「质量 × 活跃度」乘积最高的一份
2. 知识条目带图解与源码分析，面试追问到第二层也不慌
3. 目录演进紧跟行业（新增 AI 应用开发），不会越读越过时

### 不足

1. Java 语言专属章节占比高，纯 Python/Go 工程师可跳过的部分多
2. 内容体量巨大，无计划地通读容易半途而废，建议配合清单式复习
3. 部分条目与付费知识星球内容互引，免费部分的完整度有边界

### 评分理由

5 星：中文后端面试的第一参考资料，活跃维护与 Apache-2.0 许可是双重加分（⭐158.0k，截至 2026-08）。
