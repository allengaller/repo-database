## 二、技术栈分析

- 纯 Markdown 课程，按「课程表」组织：基础概念 → 分布式理论 → 组件设计 → 真实案例
- 基础部分覆盖：DNS、CDN、负载均衡、缓存、数据库分片、消息队列、一致性模型
- 案例部分为面试真题级设计：短链、限流器、推送通知、YouTube/Instagram 类系统
- 配图自绘，风格统一，比纯文字教程易消化
- 提供 PDF 导出与多语言翻译

## 三、核心功能特性

1. **课程式编排**：有先后依赖关系的学习路径，适合从零建立体系
2. **概念与案例各半**：先学原理再套到经典设计题，闭环完整
3. **图解质量高**：自绘架构图可直接用于面试白板复述
4. **篇幅克制**：比 Primer 更精简，两三周可过完一轮
5. **现代视角**：内容写于云原生时代，无过时技术包袱

## 四、应用场景说明

- 系统设计面试 4-6 周冲刺：按课程表顺序学习，比读 Primer 更省时间
- 与 [../fullstack-arch/system-design-primer.md](../fullstack-arch/system-design-primer.md) 互补：Primer 大而全适合查，本项目线性适合学
- 案例章节可直接当模拟面试题：先自己设计，再对照答案找差距
- 与 [awesome-system-design-resources.md](awesome-system-design-resources.md) 配合：本项目是主线，后者是扩展资源索引

## 五、个人评价

### 优势

1. 「学习路径」设计是同类最强：章节依赖关系清晰，不跳章不掉队
2. 自绘图解统一美观，白板面试可直接复用其画法
3. 案例选题贴近真实面试，不做无意义的玩具系统

### 不足
