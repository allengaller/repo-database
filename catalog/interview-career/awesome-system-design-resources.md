## 二、技术栈分析

- Markdown 资源索引，仓库含少量 Java 示例代码（语言统计来源）
- 组织方式按学习路径：基础 → 核心概念 → 案例 → 模拟面试 → 行为面试
- 每个资源标注形式（文章/视频/书/课程）与免费与否，过滤掉付费墙内容
- 收录大量工程博客一手链接（大厂架构文章），是二级索引
- 作者同时维护 NeetCode 路线类仓库，交叉引用

## 三、核心功能特性

1. **免费优先**：明确区分免费与付费资源，白嫖党的筛选已完成
2. **路径化索引**：不是平铺链接，按学习阶段分组，可直接当 syllabus 用
3. **一手来源**：多直达大厂工程博客原文，信息衰减少
4. **覆盖面试全流程**：系统设计 + 行为面试 + 谈薪都有入口
5. **持续维护**：最近提交 2026-02，死链清理较勤

## 四、应用场景说明

- 系统设计学习的「资源路由器」：先从这里选材料，再深入单一课程
- 与 [system-design.md](system-design.md) 配合：后者当主线课程，本项目补扩展阅读
- 找大厂真实架构文章：索引里的工程博客链接可直接作为面试案例素材
- 与 [../fullstack-arch/awesome-scalability.md](../fullstack-arch/awesome-scalability.md) 对比：后者更偏案例与事故复盘，本项目更偏学习路径

## 五、个人评价

### 优势

1. 「免费 + 分阶段」两个筛选维度做得比一般 awesome-list 细
2. 工程博客一手链接密度高，适合往深里挖
3. 更新维护在 awesome-list 中属于勤快的一档

### 不足

1. GPL-3.0 许可对二次加工分发有传染性，企业内使用需评估
2. 链接数量庞大但无质量分级，选择仍需自行判断
3. 与作者其他仓库存在交叉引流，部分条目重复收录

### 评分理由

4 星：系统设计方向的优质资源路由表，扣分在 GPL 许可与质量分级缺失（⭐40.9k，截至 2026-08）。
