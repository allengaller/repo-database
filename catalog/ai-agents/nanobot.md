## 二、技术栈分析

- Python 实现，自托管优先，强调极小依赖与开箱即用
- 与同实验室 RAG 系列（LightRAG / RAG-Anything）共享数据智能技术栈

## 三、核心功能特性

1. **个人 Agent 内核**：面向个人助理场景的最小化 Agent 循环
2. **自托管**：数据不出本机，隐私敏感场景友好
3. **多渠道接入**：可挂接消息渠道作为个人入口

## 四、应用场景说明

- 搭建私有个人助理，替代云端封闭助手
- 作为个人知识管理 + Agent 自动化的底座，可与 RAG-Anything 组合
