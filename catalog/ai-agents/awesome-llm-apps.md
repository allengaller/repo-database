## 三、技术栈与特色

### 3.1 框架中立

**不绑定特定 Agent 框架**——覆盖 OpenAI Agents SDK、CrewAI、LangGraph、AutoGen、Google ADK、Phidata 等，避免"过度依赖单一框架"风险。

### 3.2 模型中立

支持 OpenAI、Anthropic（Claude）、Google（Gemini）、xAI（Grok）商用模型 + Meta（Llama）、Qwen 等开源模型 + Ollama 本地部署。

### 3.3 完整可运行

许多项目支持 Llama/Qwen 等开源模型**在本地运行**，降低使用门槛和成本。包含 starter（入门）/ advanced（高级）/ crash_course（速成）三类，适合不同水平。

## 六、个人评价

### 优势

1. **12 万 stars，Apache-2.0** —— 商业友好、社区广泛
2. **100+ 模板** —— 覆盖广度大，从基础到高级
3. **框架中立 + 模型中立** —— 避免被特定供应商锁定
4. **强调"可运行"** —— 许多支持本地模型离线运行
5. **持续更新** —— 紧跟最新模型与协议（MCP/ADK 等）

### 不足

1. **深度参差不齐** —— 部分模板只是"能跑的 demo"，离生产还有距离
2. **Python 为主** —— 非 Python 栈开发者覆盖有限
3. **文档国际化** —— 部分模板 README 偏简单
4. **依赖外部 API 仍是主流** —— 完全离线的模板相对较少

### 评分理由

**4 星（active）** —— 12 万 stars 与 100+ 模板的数量优势；框架中立+模型中立的设计哲学；持续更新紧跟前沿。唯独"模板深度、文档质量、API 依赖"需用户自行评估。
