## 功能路线图

### P0 — 核心价值提升

#### 1. 项目详情页

**描述**：点击卡片跳转展示完整项目信息

**功能点**：
- README 摘要（截取前 500 字符）
- 贡献者数量、issue 开放/关闭数
- 项目标签/主题
- 直接跳转 GitHub 按钮
- 复制项目 URL

**实现方式**：Modal 弹窗，不刷新页面

#### 2. 收藏/书签功能

**描述**：用户可标记"宝藏项目"，localStorage 持久化

**功能点**：
- 点击书签图标收藏/取消收藏
- 书签列表页面（筛选视图）
- 导出为 JSON 文件
- 收藏时显示动画反馈

---

### P1 — 增强可玩性

#### 3. 多语言/国际化

- 前端支持中英文切换
- 语言偏好存 localStorage

#### 4. 数据统计面板

- 语言分布饼图/柱状图
- 数据更新时间
- 当前收录项目总数

---

### P2 — 体验细节

#### 5. PWA 支持

- Service Worker 离线缓存
- 添加到主屏幕提示

#### 6. 键盘快捷键

- `/` 聚焦搜索框
- `Esc` 清空筛选
- `T` 切换主题
- `B` 切换书签视图

#### 7. 性能优化

- 虚拟滚动（大数据集）
- 卡片懒加载动画

---

### P2 — 数据增强

#### 8. 新数据源

- Hacker News
- DEV.to
- Reddit r/programming
